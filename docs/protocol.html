01 · Study scope

The primary study uses 16 training slides per class, five patient-disjoint folds, and two visual encoders: PLIP and CLIP-RN50. It includes six architectures: ViLa-MIL, MGPATH, FOCUS, MUSE, HiVE-MIL, and DyKo.

Each common cohort intersects slide availability with fixed TME coverage. Architectures reuse the parent cohort manifests, ordered folds, and donor maps. Training, validation, and test patients do not overlap within a fold. Magnification and architecture-specific feature organization are preserved.

The 4- and 8-shot ViLa-MIL/MGPATH extension is a separate study axis. This website describes the TCGA TME-conditioned study.

02 · The TME conditioner

Quantitative measurements are grouped into 16 biological tokens. A trainable cross-attention module reads these tokens and adds a gated residual to an architecture’s existing visual centers or encoded semantic queries. The native model’s parameters remain frozen and in evaluation mode during adaptation.

Whole-slide features enter the native visual aggregation directly. Biological measurements enter through the conditioner. Median imputation and standardization are fitted using only the 32 training slides in each 16-shot fold; those fitted statistics are applied to validation and test slides.

Guided inference uses TME. The actual-TME arm needs a slide’s biological measurements when making its prediction. This study does not establish a WSI-only distilled model.

03 · Four matched conditions

  • Native: the eligible matched baseline before adding the TME conditioner.
  • Zero TME: standardized measurement values are set to zero. Learned group identities and conditioner capacity are retained.
  • Actual TME: the conditioner receives the recipient slide’s own measurements.
  • Shuffled TME: a frozen, label-blind whole-row bijection supplies measurements from a different patient within the same training, validation, or test split.

Actual, zero, and shuffled arms share initialization, capacity, and selection rules within each architecture/encoder/cohort/fold. The shuffle preserves row marginals and missingness. It excludes the recipient’s patient, but it is not a patient-block permutation for patients with multiple test slides.

Native checkpoints are eligible for reuse only when the configuration and exact ordered split membership match. Otherwise, the native recipe is fitted on the common-cohort fold.

04 · Why these biological features?

The panels are hand-defined biological hypotheses, based on the available quantitative OpenTME measurements. Selection starts with observable tissue structure, cell populations, and local cell interactions. Identifiers, labels, and project metadata are excluded from the biological input.

Related measurements share a token: for example, regional cell composition or a particular cell population’s spatial relationship to carcinoma. The design does not manually pair a feature with a prompt phrase, and it does not establish an optimal or exhaustive panel.

NSCLC · core62

  • 14 tissue measurements: global and regional tissue composition, including tumor core and margin.
  • 28 cell measurements: seven cell types in two regions, measured by percentage and density.
  • 16 spatial measurements: lymphocyte, macrophage, fibroblast, and plasma-cell proximity to carcinoma at two radii, using two measurement types.
  • 4 lymphoid measurements: derived tertiary lymphoid structure (TLS) presence and count features.

The 16 tokens comprise five low-scale and eleven high-scale groups. The inherited panel uses a legacy zero-count convention for absent TLS counts.

BRCA · morph64

  • 24 tissue structure and morphology measurements: five slide tissue proportions, eight carcinoma/stromal geometry measurements, three core/margin extent measurements, and eight regional composition measurements.
  • 28 cell measurements: the same seven-cell-type, two-region, two-measurement structure.
  • 12 spatial measurements: fibroblast, lymphocyte, and macrophage proximity to carcinoma at two radii, using two measurement types.

The 16 tokens comprise six low-scale and ten high-scale groups. This panel emphasizes carcinoma and stromal architecture. Its exclusion of TLS reflects that hypothesis; it does not demonstrate that TLS is uninformative.

05 · Architecture-specific connections

The shared interface is adapted to each model’s existing computation. Original prompt strings stay separate from quantitative TME measurements.

TME entry point for each architecture
ArchitectureVisual scaleConditioned representation
ViLa-MIL5× + 10×Low- and high-scale image-center queries, before native patch aggregation.
MGPATH5× + 10×64 image-center queries before native graph aggregation; text and transport paths stay frozen.
FOCUS20×Encoded semantic class queries before relevance ranking and final visual cross-attention.
MUSE10×Inference class semantics before sparse expert routing; the training-only retrieval bank remains separate.
HiVE-MIL5× + 20×32 encoded hierarchical text nodes before filtering and graph construction: four coarse and twelve fine nodes per class.
DyKo20×Two class queries after native concept retrieval and before visual/semantic cross-attention.

Discrete top-k choices, retrieval indices, and graph edges are not differentiable. Continuous attention and graph computations provide the conditioner’s training signal. DyKo’s concept knowledge banks are separate assets from the core62/morph64 biological measurement panels.

06 · Research boundaries

This is exploratory research. Architecture and cohort follow-ups were selected after earlier experiments had been inspected. Fixed folds and matched controls preserve the comparison design; they do not turn it into an untouched confirmatory evaluation.

The paired PLIP/RN50 ports include explicit PathoTME extensions. They should be interpreted with their documented projection, context, and native token-consumption rules. For example, HiVE-MIL retains source text while recording native 77-position consumption and truncation.

TME group attention is a diagnostic of model computation, not a causal explanation or word-level text attribution. Historical feature headers establish encoder identity, dimensions, and geometry, while original feature-extraction checkpoint digests are unavailable.

07 · Data and code

Quantitative phenotypes are provided by Aignostics / OpenTME. The downloadable biological panel definitions record the pinned dataset revision, ordered feature names, and source columns. No individual patient measurements are included.

The anonymous code repository contains the conditioners, feature definitions, study configurations, and architecture-specific implementations.
